# 后端稳定性

使用 Python 3.11+，推荐 Python 3.12。后端默认仍通过 `uvicorn app.main:app` 启动。

## 数据库与上传

- 文件型 SQLite 连接启用 WAL 和外键，读请求不会阻止正常写入；数据库应放在本地磁盘。备份运行中的数据库应使用 SQLite backup API，不能只复制 `.db` 而遗漏 WAL。
- `ORALSCAN_SQLITE_BUSY_TIMEOUT_SECONDS` 默认 10 秒。锁等待耗尽或连接池耗尽返回 `503 DATABASE_BUSY` 和 `Retry-After: 1`，其他数据库错误仍返回不含 SQL 参数的结构化错误。
- 图像校验、文件写入和网格解析在工作线程运行；耗时处理期间释放数据库连接。并发上传在短写事务内重新读取检查记录，避免覆盖来源类型；检查已被删除时清理新增文件并返回 404。
- 上传仍受文件大小、请求体接收截止时间及网格解析 15 秒超时限制。退出服务时释放数据库连接池。
- 上传先在私有 `pending_uploads` 目录校验，取得写锁并确认检查仍存在后才移入正式目录；失败会清理临时文件。删除失败时先恢复目录再释放写锁，避免并发上传妨碍恢复。强制终止进程可能留下临时文件，应在服务停止后清理。
- 图片上传会验证像素解码，拒绝仅文件头完整的截断 JPEG。检查元数据在入库前拒绝非有限数值和无效 Unicode。

## 资源限制

以下容量均按**后端进程**计数，多 worker 会增加总容量和内存占用。默认单 worker 适合本地运行。

| 工作 | 同时处理上限 | 超额响应 |
| --- | --- | --- |
| 上传校验及保存 | 4 | 503 `UPLOAD_BUSY` |
| 图像推理 | 2 | 503 `INFERENCE_BUSY` |
| 模型加载 | 1 | 503 `MODEL_LOAD_BUSY` |
| 三维几何分析 | 2 | 503 `GEOMETRY_BUSY` |
| 报告生成 | 2 | 503 `REPORT_BUSY` |
| AI 助理生成 | 默认 2，可配置 | 429 `ASSISTANT_BUSY` |

上述 503 容量响应包含 `Retry-After: 1`。客户端可稍后重试，应避免无间隔重复提交。

`ORALSCAN_ASSISTANT_MAX_CONCURRENT_REQUESTS` 可设为 1–32。Ollama/DeepSeek 超时配置同时限制整个上游请求时长；成功响应正文限制为 512 KiB，超大或无效响应返回网关错误，异常、超时和取消均释放容量与连接。上游错误正文不会展示给用户。

ONNX 每个会话最多使用 4 个算子内线程、1 个算子间线程，并关闭线程忙等。推理期间不持有数据库写锁；检查被并发删除时不会恢复其任务。报告列表及下载不加载完整预览快照，图片先缩略再转换，减少内存占用。

这些限制不构成持久化任务队列。服务被强制终止时，已提交的 `running` 分析可能保留该状态，需要重新发起分析；当前未实现自动恢复或模型进程隔离。

## 验证

在 `backend` 目录及已安装 `requirements.txt` 的虚拟环境中运行：

```powershell
python -m pytest -q
```

测试覆盖数据库锁、并发删除、上传响应性、事务失败清理、计算限流、上游超时/取消/异常和报告内存加载路径。AI 上游使用模拟响应；测试不需要付费 API 密钥或下载 Ollama 模型。ONNX 测试使用生成的小模型，不能代替真实业务模型的性能测试。

GitHub Actions 在 Windows、Ubuntu 的 Python 3.12 环境执行后端测试。网格夹具保留原始字节和 LF 换行，确保跨平台校验一致。
