# Phase 6 三维几何分析

该管线独立于二维 AI，仅检查网格与计算几何量，任何质量警告都不代表疾病或诊断。对已导入的 3D 资产，`POST /api/scans/{scan_id}/assets/{asset_id}/geometry-analysis` 执行分析；`GET` 同一路径读取最近结果。原始资产 SHA-256 在处理前复核，结果存入 `AnalysisJob.result_summary`，不会覆盖原始文件。处理在独立子进程中执行，限制 20 秒；失败也记录任务和警告。主进程或系统异常退出时，已记录的运行中任务可能需要重新发起。

`MeshAnalysisResult` 包含 `asset_id`、`job_id`、`geometry_metrics`、`mesh_quality`、`coordinate_system`、`warnings`、`processing_time_ms`、`status` 和 `source_sha256`；每项测量均有 `status`、`value`、`reason` 与可选单位。处理时间为工作进程内的计算时间，不包括进程启动和网络传输。

- 输入为空、无法解析、顶点非有限、索引无效或超出限制时返回失败；不能计算的项目值为 null、状态为 unavailable。上传阶段已拒绝的空文件仍可由分析模块直接处理并产生失败结果。
- 顶点和面计数基于 Trimesh 加载后的表示，导入器可能重排或省略未引用顶点；它不是对所有格式原始文件记录数的保证。重复顶点检查采用加载结果中的**完全相同坐标**；STL 常因逐面存储出现重复点。
- 退化面使用三角形叉积长度与包围盒最大跨度平方的 `1e-12` 倍比较。计算的面法线由三角形几何导出；STL 面法线、OBJ `vn`、PLY 顶点 `nx/ny/nz`（存在时）另检查向量是否有限且非零，但不检查它们与面的对应关系或方向。无源法线时明确标记 unavailable。
- 连通分量按内存副本顶点合并后的**顶点连通性**计算，点接触的区域会归为同一分量。原始文件、坐标和索引不被修改。
- 孔洞指标为可识别的闭合边界环数量，分支边界无法可靠计数时返回 unavailable；它不等价于解剖孔洞，也不检测自相交。封闭性与绕序单独记录。
- 体积只在网格封闭、绕序一致、无退化面且 Trimesh 判定正体积时返回；否则为 null 并给原因。即使有值，它也是代数体积，尚未验证自相交或嵌套壳，因此不得解释为临床测量。
- 原点和轴方向以源文件为准，不推断解剖方向。当前变换为 4×4 单位矩阵、缩放为 1；单位为导入时选择的 `unknown`、`mm`、`cm` 或 `m`，不擅自换算。

保留 `MeshRegionReference` 类型供未来接收实际区域数据，需要资产、源文件哈希、源顶点/面索引和来源。当前没有区域上传、分割或高亮功能；即使有未来数据，也必须先核实其索引与展示网格的对应关系，不能假定不同加载器的顶点顺序一致。
